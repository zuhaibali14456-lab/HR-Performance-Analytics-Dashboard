# HR-Performance-Analytics-Dashboard
Developed an interactive HR Analytics dashboard to analyze employee performance, productivity, and workforce insights.
Analyzed department-wise salary trends, employee satisfaction, project completion, and workforce distribution by gender and position.
Performed data cleaning, transformation, and data modeling using Power Query and DAX.
Created interactive visualizations to convert HR data into meaningful business insights and support data-driven decisions.

Tools: Microsoft Power BI, Power Query, DAX, Data Modeling, Data Visualization
